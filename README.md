# Polar Coordinates: A Visual Explanation

This project is an animated visual explanation of polar coordinates created using Manim. It focuses on building intuition rather than memorization, showing how circular motion naturally leads to sine, cosine, and the polar coordinate system.

The animation is designed for students learning trigonometry, precalculus, calculus, physics, and engineering.

## What This Project Explains

This animation answers the following questions visually:

- What does a polar coordinate (r, θ) actually represent?
- Why do we use sine and cosine in polar coordinates?
- How do x = r cos(θ) and y = r sin(θ) arise from geometry?
- How can we convert between Cartesian and polar coordinates?
- Why are polar coordinates important in physics and engineering?

Rather than presenting formulas first, the animation builds understanding from rotation, geometry, and projection.

---

## Concepts Covered

- Polar coordinates (r, θ)
- Cartesian coordinates (x, y)
- Unit circle and rotation
- Sine and cosine as projections
- Converting between coordinate systems
- Applications to waves and signals
